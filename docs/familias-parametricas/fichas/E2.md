## Contexto
`packages/io/src/ifc/ifcComponentes.ts` exporta `IFCFURNITURE` com `IFCTRIANGULATEDFACESET` (veja `ifcComponentes.test.ts`). CONTRATO.md §6.

## Faça
1. Use `classeIfcDaFamilia` (E1) para a classe da entidade; inclua a malha dos corpos (`malhaDosCorpos`) no mesmo conjunto de faces; aplique `matrizDoComponente` (B1) na colocação.
2. Para cada ligação resolvida gere `IFCDISTRIBUTIONPORT` (fluxo → `FlowDirection`, domínio → `SystemType`) com `IFCRELCONNECTSPORTTOELEMENT`; para cada `Component.ligacoes` gere `IFCRELCONNECTSPORTS` uma vez por par. Propriedades de tipo e instância em `Pset_HestiaFamilia`.
3. Testes: tubo → `IFCPIPESEGMENT` com 2 portas; curva → `IFCPIPEFITTING`; par conectado gera 1 relação; família antiga continua `IFCFURNITURE` com saída idêntica (compare o texto IFC antes/depois nos casos existentes).
