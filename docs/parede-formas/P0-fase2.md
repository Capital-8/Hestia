# P0 da Fase 2 (parede inclinada): mapa do código

Só leitura; base `frente/parede-formas` (057052f1). Caminhos relativos à raiz.

**Efeito nas estimativas (3 linhas):** o sólido 3D, a planta, o corte e os quantitativos da parede são TS; o Rust só espelha (despacho com flag, padrão desligado), então F2.3/F2.5/F2.6/F2.7 ficam em TS e sem contrato novo.
O risco novo é a junção do Rust (`juncoes.rs`): F2.4 vale nas duas linguagens, e com a flag ligada o Rust ignora o `tilt` (coluna inexistente); ou se cria coluna e sobe o contrato (19 para 20), ou o despacho cai para TS quando houver parede inclinada (recomendado, F2.1/F2.4).
F2.11 é mais barata: quase tudo é spread dentro dos comandos do modelo (`commands.ts`), só Espelhar e a troca a/b exigem código.

## Respostas
1. **Sólido 3D: TS.** `packages/render/src/model3d/solids.ts:356` (`wallLayerSolid`) extruda faixas (`LayerBand`) vindas de `wallLayerBandsAfterJunction` (`junctionLevel.ts:285`), em reta e arco, com camadas; o vão é cortado pelo TS (`openingCut.ts`). Não existe malha de parede no Rust (só `massa_malha`, `cortina_malha`, `gc_malha`). Planta: `resolve.ts:405` (`resolveLevelTs`) para `render/plan/build.ts:390`. Corte: `engine/section.ts:298` e `sectionCut.ts`. Quantitativos: `engine/quantities.ts:58`, que usa o resultado do Rust quando o despacho está ligado (`quantities.ts:70`, `quantidades.rs:238`) e senão calcula em TS (`junctionNet.ts`). O cache de camada (`solids.ts:349`) não tem `tilt` na chave.
2. **Junções: duas implementações.** TS `joins.ts:174` (`computeEnds`, `estruturaDasJuncoes` em `resolve.ts:~411`) e Rust `juncoes.rs` (porte), ponte `kernelA1.ts` (`montarCenaA1` l.56, `referenciaA1` l.226). Em produção vale o TS: a flag é `kernelFatiaLigada` (`packages/geom/src/kernel/v2/fatias.ts:79`: URL `?kernel=rust` ou `?kernelFatias=`, ou `localStorage` `hestia:kernel...`; padrão = nenhuma fatia, ou seja, TS), com `resolveLevel` (`resolve.ts:399`) despachando via `kernelDespacho.ts:352` e `kernelDespachoA.ts`. A junção de pisos e lajes (fatia B) também passa por `resolverJuncao` (`kernelDespacho.ts:160`). Modo sombra: `hestia:kernel:sombra`. Paridade TS x Rust (rodam em `npm run test:wasm`): `tests/kernel-a1.wasm.test.ts` (1 µm, topologia exata), `kernel-a2.wasm.test.ts` e `kernel-a2-referencia.test.ts`, `kernel-b3*.test.ts`, `kernel-b7-parede-inclinada.wasm.test.ts` (nome enganoso: é topo inclinado sob laje, não `tilt`), `kernel-b6-quantidades.wasm.test.ts`; comparadores em `packages/engine/src/kernelCompara*.ts`; testes unitários de junção só TS em `packages/engine/src/junction*.test.ts`.
3. **Contrato.** O Wall NÃO trafega como JSON: o contrato é colunar binário, `crates/geom-wasm/schema/cena-v11.json` espelhado em `crates/geom-wasm/src/esquema.rs` (`VERSAO_ESQUEMA = 19`, l.8; seção `paredes` l.197 e `paredes_quadro` l.211, esta com `sag`, `z0`, `topo`, montada em `kernelA1.ts:142`). Campo opcional novo em `Wall` é ignorado pelo Rust (só vão as colunas listadas); não precisa subir o contrato para o app funcionar. Subir só se o Rust precisar do `tilt` (nova coluna em `paredes_quadro`, JSON + `esquema.rs` + `kernelA1.ts`, 19 para 20, teste `contrato_confere_com_json`). O esquema do projeto é outro número: `SCHEMA_VERSION = 26` em `types.ts:28`; migrações em `migrate.ts:30` (`migrations[n]` leva n para n+1; última é `25` na l.277; `migrateProject` l.285).
4. **Comandos do modelo:** `makeWall` (`packages/model/src/wall.ts:10`, defaults + `...w`), `addWall` (`commands.ts:108/364`), `updateElements` (l.153/462, patch por spread: `{ ...e, ...c.patch }`), `transform` (`transformWall` l.237, spread `{...w}`: preserva `tilt`; Espelhar precisa inverter o sinal), `splitWall` (`splitWall.ts:68` spread `...w`: preserva), `setElementLevel`. Ferramentas (todas passam por esses comandos; nenhuma monta Wall campo a campo):

   - Matriz: `arrayTool.ts`, `arrayRadial.ts` (l.97) = `transform` com cópia (preserva).
   - Deslocar: `offsetTool.ts` (l.212 a 226), `offsetChain.ts`, `parallelTool.ts` = `copyWalls` + `updateElements` de `a/b/sag` (preserva).
   - Aparar/Estender: `trimTool.ts`, `trimChange.ts`, `trimPreview.ts:23` (`patchCommands`), `trimAlign.ts` = `updateElements` só de `a/b/sag` (preserva).
   - Dividir: `splitTool.ts:348` = `splitWall` (preserva).
   - Alinhar: `alignTool.ts`, `alignApply.ts:48` = `transform` translate (preserva).
   - Arrastar parede com vizinhas: `wallFollow.ts:112`; alças: `selectGrips.ts:152` (preservam).
   - Cria Wall nova só `wallTool.ts:333` (`makeWall`) e `ifcImport/mapping.ts` (`makeWall`).
   Conclusão: `tilt` é preservado de graça em todos; trocar `a` por `b` (nenhum comando atual troca) e Espelhar (`commands.ts:243`) exigem inverter o sinal à mão.
