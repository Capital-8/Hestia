# Hestia 0.2.2

## Instaladores Linux

- O Hestia passa a ter pacotes para **Linux** no mesmo Release do instalador Windows:
  **AppImage**, **`.deb`** e **`.rpm`** (x86_64).
- Requisitos: Ubuntu 22.04+ / Debian 12+ (o build usa glibc 2.35), com WebKitGTK 4.1 e GTK 3.
  O `.deb` já declara `libwebkit2gtk-4.1-0` e `libgtk-3-0` como dependências; o AppImage é
  autossuficiente (os arquivos `.sig` do atualizador acompanham os pacotes).
- Atualização automática no Linux vale para quem usa o **AppImage**. Quem instalou por
  `.deb`/`.rpm` recebe a versão nova pelo gerenciador de pacotes.

## Sobre esta versão

- **Não há mudanças funcionais no programa** em relação à 0.2.1: é a mesma versão do app,
  com os instaladores Linux e os metadados dos pacotes.
- O site (`/app`) passa a receber, no mesmo Release, o `index.html`, os três workers e o
  `geom_wasm.wasm` carimbados com a versão.

## Problema conhecido

- Em máquina virtual ou ambiente sem aceleração gráfica, o WebKitGTK pode encerrar ao abrir.
  Nesses casos, rode com `WEBKIT_DISABLE_COMPOSITING_MODE=1 WEBKIT_DISABLE_DMABUF_RENDERER=1
  LIBGL_ALWAYS_SOFTWARE=1` (detalhes em `docs/desktop.md`). Em máquina física com GPU o
  comportamento normal continua.
