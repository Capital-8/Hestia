## Como compilar o app desktop no Windows

- Precisa do Visual Studio Build Tools 2022 com a carga "Desenvolvimento para desktop com C++" (`winget install Microsoft.VisualStudio.2022.BuildTools`). Sem isso o Rust não acha o `link.exe`.
- Rodar pelo **PowerShell**, não pelo Git Bash: o `link` do coreutils do Git Bash sobrepõe o `link.exe` do MSVC.
- `npm install` na raiz (senão falta `openskp` e o `vite build` falha).
- `NODE_OPTIONS=--max-old-space-size=8192 npm run build` na raiz, depois `npx tauri build --debug --no-bundle` em `desktop`. Primeira compilação: ~47 min.
- Se aparecer "Erro nos dados (verificação cíclica de redundância)", apagar os artefatos `hestia_desktop*` em `desktop/src-tauri/target/debug/deps` e repetir.
