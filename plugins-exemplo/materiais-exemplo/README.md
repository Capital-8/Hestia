# Materiais de exemplo (suplemento declarativo)

Só JSON, sem código. Contribui três materiais de acabamento (reboco claro, porcelanato grafite, vidro verde).

- Nada entra no projeto ao instalar ou ativar: use **Suplementos > Gerenciar suplementos > Carregar conteúdo**.
- Os materiais entram como `dev.hestia.materiais-exemplo:<id>`; os materiais do projeto não são alterados.
- Cada material tem `color` (#rrggbb), `gloss` (brilho, de 0 a 1) e `opacity` (opacidade, de 0 a 1).
- A carga é um único passo de Desfazer; remover mantém o que ainda estiver em uso.
